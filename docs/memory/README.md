# Project Memory & Documentation

This directory (`docs/memory/`) serves as a central knowledge base for the project, capturing key context, guidelines, and evolving understanding.

## Contents:

*   **`project-overview.md`**: High-level summary of the project's goals and purpose.
*   **`technical-architecture.md`**: Description of the system's architecture.
*   **`development-guide.md`**: Guidelines for development practices, setup, and workflows (potentially overlaps with specific rule files).
*   **`planning_workflow.md`**: The mandatory step-by-step planning process derived from project rules.
*   **`general_rules.md`**: Core rules and principles to be followed throughout the project lifecycle.
*   **`directory_structure.md`**: The standard directory layout for the project.
*   **`lessons-learned.md`**: A living document capturing important findings, patterns, and solutions discovered during development.

Refer to these documents to understand project standards, history, and context.
